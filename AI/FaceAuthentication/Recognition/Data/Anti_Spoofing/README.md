# 🛡️ Face Anti-Spoofing (FAS) & Liveness Dataset Split

Contains sample images for evaluating liveness detection and presentation attack detection (PAD).

## Subdirectories:
- `real/`: Genuine live human faces captured directly in front of the camera.
- `spoof/`: Presentation attacks including:
  - 2D printed photo attacks (matte, glossy, folded, cut-out paper masks).
  - Digital screen replay attacks (faces displayed on smartphone, tablet, or laptop screens).
